## 一、视频重磅干货拆解：孙宇晨对话核心观点

### 1. 个人全方位 100% AI 化（零成本启动路线）

- **生活与健康数据化**：把餐前餐后照片丢给 AI 计算卡路里与蛋白结构，结合 Oura 智能戒指监控睡眠与代谢，将健身训练视频上传给 AI 进行渐进式超负荷（Progressive Overload）记录，每日自动生成 Markdown 格式的健康与工作日报。
- **零成本/低成本切换模型**：预算有限（如月可支配收入不足千元）的年轻人不必追求高昂订阅。使用免费或高性价比的 API（如智谱、Kimi 等），将所有数据保存在本地 Markdown 文件中，随时更换 AI 底座，实现无缝切换。
- **人机协同模式**：**90% 自动驾驶 + 10% 人类微调**。面对重大决策时，向中美 3 个顶尖大模型同时提问，"取其中"做最优判断。

### 2. 三大底层认知操作系统

> "认知决定命运，其实一切都是认知。" —— 孙宇晨

- **孙学（思想操作系统升级）**：对金钱、财富自由、科技趋势进行操作系统级别的重构。
- **搏击理论（碳基服务器硬件维护）**：身体是承载大脑与决策的"碳基服务器"，肌肉与心肺占寿命质量评分的 50%。肌肉是身体的"现金资产"与被动燃脂装备，20–40 岁必须主动积累肌肉量。
- **黄毛理论（Small Ego 与抗干扰心态）**：保持小自我（Small Ego），不受传统偏见、社会嫉妒或质疑所干扰，逻辑验证正确就极速执行，敢于做异类。

### 3. 极速行动策略与生存原则

- **"探图"策略（消除信息不对称）**：借鉴即时战略（RTS）游戏逻辑，在做选择（选专业、职业规划、买房）前，先用 AI 把"全图打通"，看遍 100 种选项后再做针对性布局，避免闭门造车。
- **"逐水草而居"与极强机动性**：避免过早被房产、车产等重固定资产绑死在单一城市，保持随时前往高价值地区的流动性。
- **全球价值流动与服务扩张**：跳出本土内卷，结合 AI 杠杆，利用全球信息差与价格服务（如 Token 与 API 跨国服务），面向全球 80 亿人类及数十亿 AI Agent 提供服务。

### 4. 高潜赛道与趋势判断

- **数据密集型科学与学术**：AI 打破门槛（"乱拳打死老教师"），数学（形式化证明）、天文学、生物基因与制药等拥有海量待处理数据的领域将迎来爆发。
- **机器可读资产与 Web3/Crypto**：Crypto 是将传统货币"翻译"为 AI 和机器可读可编程语言的工具，天然适配 AI Agent 间的 API 级高频微支付与秒级结算。
- **主动健康管理**：从"生病才去医院"转向通过 AI+智能硬件实时监控与预警的"主动健康管理"。

## 二、认知程序化：提炼 `SKILL.md` 智能体技能

孙宇晨在视频中强调："**如果一个东西没有被翻译成机器读得懂的语言，它就没有办法被全世界的 AI 消化和使用。**"

为了让 AI Agent 能够直接"继承"这些认知，我们把它提炼成了一个符合标准规范的 `SKILL.md` 技能文件——**`decision-scout`（决策探图）**：

- **名称**：`decision-scout`
- **定位**：在重大决策前，先替你"探图"的 Agent 技能。把"我该怎么办"拆成工程问题。
- **原则一：先数据化，再给建议**。没填完资产表，它只提问、不给建议。
- **原则二：AI 优先与数据结构化**（Markdown 本地存储，底座可换，90% AI 驾驭 + 10% 微调）。
- **原则三：先探图再决策**。铺开 3–5 条非常规路径，用激进派 / 稳健派 / 逆向派三个视角交叉拷问，明确指出三者分歧在哪。
- **原则四：打分收口**。对选定路径打三项分——**机动性 / AI 杠杆率 / 全球化与机器可读潜力**，最后给一份 30 天最小可行行动清单。

写进技能里的四条铁律：**没数据不给建议 · 不承诺结果 · 重大决策不给单边结论 · 每个建议必须说清代价**。

## 三、如何从 GitHub 获取并使用这个 Skill？

该 Skill 已开源托管在 GitHub 上，MIT 协议，随便用、随便改、随便商用。

### 1. 仓库地址（长按复制）

```
github.com/jmsjbeb/decision-scout
```

> 公众号正文里的链接点不动，建议把"**阅读原文**"设为这个仓库地址。

### 2. 仓库里有什么

你可以选择以下任意一种方式获取：

- **克隆仓库**：终端执行 `git clone` 获取完整仓库。
- **打包下载**：直接在 GitHub 页面点 **Code → Download ZIP** 解压使用（不写代码的人用这个）。

仓库内已经整理好了各种 Agent 框架可以直接读取的配置：

- **`SKILL.md`**：技能本体——四条铁律 + 三阶段工作流（支持主流框架直接加载）。
- **`configs/hermes_skill.json`**：适用于 Hermes Agent 框架的专属技能配置。
- **`configs/openclaw_config.json`**：适用于 OpenClaw 的工作流节点配置（做成了 intake → scout → evaluate 三节点）。
- **`configs/workbuddy_agent.json`**：适用于 WorkBuddy 个人智能体。
- **`configs/codex_assistant.json`**：适用于 Codex / Assistant API 导入。
- **`adapters/loader.py`**：把 `SKILL.md` 一键转成任意框架的 system prompt / JSON 配置。
- **`tools/dashboard.py`**：零依赖小工具，把你填的资产表渲染成**单文件 HTML 仪表盘**（资产表 + 三项评分条形图 + 30 天清单）。**不需要装任何依赖，不需要 API Key，数据不出你的本机。**
- **`examples/asset-table.example.md`**：可直接填写的资产表模板。

### 3. 三种快速上手方式

1. **当作系统 Prompt 使用**：把 `SKILL.md` 的内容拷进 Agent 的 System Prompt 即可。
2. **框架加载配置文件**：直接把 `configs/` 里对应的 JSON 载入系统。
3. **跑一遍仪表盘工具**：

```bash
cp examples/asset-table.example.md my-assets.md
# 填完表格后：
python tools/dashboard.py my-assets.md -o dashboard.html
```
