# 我做决定前，会让 AI 先把地图上的战争迷雾开完

## 一、先看一个你熟悉的场景

你在对话框里打下一行字：

> 我该不该辞职，all in AI？

然后你得到三段正确的废话：

> 需要综合考虑风险与收益，评估现金流，结合自身情况再做决定……

不是它不聪明。是**你的问题里，没有它可以执行的流程**。

## 二、烂决策的根因：你拿着一张 10% 可视度的地图在推理

打即时战略游戏的人都知道一条铁律——

**你不会直接走进战争迷雾。**

先派侦察兵探图：资源点在哪、地形怎么走、对手开局什么流派。图探完了，再决定在哪落脚、往哪投兵。

而现实里，大部分人做重大决策——选专业、换城市、要不要买房、要不要 all in 一个方向——都是在**10% 可视度的地图上硬推**。

依据是什么？听来的三句话、刷到的两个视频、一位「过来人」的经验。

这不是推理能力差，这是**信息不对称**。

我在一场公开访谈里听到过一个说法，当时就被点住了：**做选择前，先用 AI 把「全图」打通，看遍 100 种选项，再做针对性布局。** 反对闭门造车。

这句话我琢磨了很久，然后意识到一个问题：

**它是观点，不是流程。**

"先探图"谁都同意。但具体怎么探？探完看什么？看完怎么比？——没人定义过。

所以我花了点时间，把它定义出来了。

## 三、它长什么样：一个装进 AI 的「技能」

Agent Skill 这个概念，你可以粗暴理解成：**给 AI 挂一份 SOP 文件**。命中场景时自动加载，AI 就按这份 SOP 干活。

项目叫 **decision-scout**（决策探图）。

它干的唯一一件事：**在你做重大决定之前，把选项从「隐隐约约几个」铺开到「清清楚楚一堆」，然后给你一张打分表。**

流程被写死成三个阶段，顺序不能跳：

**阶段一 · 资产审计**

先别聊方案。它要你先把现状交出来：

- 时间资产：每天可自由支配几小时、时间主要去哪了
- 资金资产：月可支配收入、能承受的试错预算、现有固定负债
- 健康资产：睡眠、运动频率、已有数据源
- 能力资产：核心技能、哪些部分能被 AI 放大、有什么可验证的作品
- 认知资产：当前最大的困惑、已经收集到几个选项

**这里有一条铁律：表不填完，它只提问，不给建议。**

为什么这条重要？因为一个在你没给数据时也照样侃侃而谈的助手，只是在**用更高级的词汇猜**。

**阶段二 · 探图**

基于你的表，它铺开 **3–5 条非常规路径**，每条必须带四件事：

> 路径描述 · 前置条件 · 最短验证周期 · 失败成本

然后是最关键的一步——**三视角交叉**：

- **激进派**会怎么看
- **稳健派**会怎么看
- **逆向派**会怎么看

并且明确告诉你：**这三个人分歧到底分在哪**。

最后补一份「你还缺哪些信息 + 拿到它们的最低成本方式」。

**注意：这一阶段它被禁止给你结论。**

**阶段三 · 打分与收口**

你选定一条路之后，它打三项分（1–10）：

- **机动性** —— 这条路会锁死你多少行动自由？（越高越自由）
- **AI 杠杆率** —— 这条路的边际成本里，有多大比例能被 AI 压到趋近于零？
- **全球化 / 机器可读潜力** —— 你的交付物能不能跨地域触达？能不能被机器直接消费？

最后给一份 **30 天最小可行行动清单**：不超过 5 条，每条必须带完成标准。

## 四、打个样：真实的前后对比

问题还是那个问题，换成更具体的：

> **我该不该搬去一个生活成本更低的城市省钱？**

**没有 skill 的时候**，AI 会告诉你：要计算搬迁成本、考虑就业机会、评估生活质量、建议先调研……

**装上之后**，输出是这样（节选）：

> **先审计。** 回答之前我需要 4 个数：月固定支出、收入可迁移性（能不能远程赚钱）、当前租房/资产锁定期、你已经调研过几个方案。这是要填的表。
>
> **探图。** 假设收入可远程，三条路：
> (a) 立刻搬，把差价存下来 —— 代价：丢掉本地人脉，且难撤回；
> (b) 再待一个租期，把差价换成 AI 杠杆更高的技能 —— 代价：延迟存款约 12 个月；
> (c) 不搬，把差价用来买**选择权**（现金跑道、设备、资质）—— 代价：风险最低，上限也最低。
>
> **三视角的分歧点** —— 激进派说马上搬、以后再优化；稳健派说把搬迁成本和重建人脉算进去，省下的钱可能是幻觉；**逆向派说这个问题本身就问错了** —— 你该先验证收入可迁移性，因为那才是决定前两条路能不能走通的变量。
>
> **评分** —— 机动性 7/10 · AI 杠杆率 4/10 · 全球触达 6/10。**最弱维度是杠杆。**
>
> **30 天计划** —— [5 条，各带完成标准]

你注意到了吗：真正有价值的那句话，是**逆向派**给出的。

而单人视角的回答里，它永远不会出现。

## 五、它不只是一份提示词：附带一个能跑的工具

这一点我特意做了。因为纯提示词的项目，看的人多、用的人少。

仓库里带了一个零依赖脚本 `tools/dashboard.py`：

```bash
cp examples/asset-table.example.md my-assets.md
# 填完表格后：
python tools/dashboard.py my-assets.md -o dashboard.html
```

它把你填的 Markdown 资产表，直接渲染成一张**单文件 HTML 仪表盘**——资产表 + 三项评分条形图 + 30 天清单，一个文件、双击就开。

**不需要装任何依赖，不需要 API Key，数据不出你的本机。**

（用 Python 标准库写的，不联网、不上传、没有偷偷回传。这一点对做个人资产规划来说很重要。）

## 六、怎么用：三种方式，从零代码到全定制

**方式一 · 零代码（推荐先试这个）**

```bash
git clone https://github.com/jmsjbeb/decision-scout.git
mkdir -p ~/.claude/skills/decision-scout
cp decision-scout/SKILL.md ~/.claude/skills/decision-scout/
```

之后正常问问题，命中时自动加载。

**方式二 · 给任意 API 生成 system prompt**

```bash
python adapters/loader.py --format system-prompt
```

纯标准库、无依赖。输出的文本直接贴进 OpenAI / Claude / 本地模型 / Coze / Dify 任意位置，一分钟接完。

**方式三 · 跑仪表盘工具**（见上一节）

**已适配的框架**：Claude Code / Claude.ai Skills、WorkBuddy、Hermes、OpenClaw（做成了 intake → scout → evaluate 三节点工作流）、OpenAI Codex / Assistants API。配置文件都在 `configs/` 里，往 `configs/` 丢一个小 JSON 就能补新框架。

## 七、最后说两句实话

做这个技能的过程中，我自己最大的收获不是那个文件，是**被迫把"探图"想清楚了**。

"先看遍 100 个选项再决定"——这句话反过来听，意思是：**你现在的纠结，很可能不是因为你选不出，是因为你根本没把选项列全。**

在 3 个选项里反复权衡，和在 30 个选项里权衡，是完全不同的两件事。

前者叫纠结，后者才叫决策。
